# Agent instructions

## Most important: be reader friendly

- Every file must be skimmable, clear and concise. Use bullets where you can.
- Name things so they explain themselves. A headline number that needs two paragraphs, or needs the reader to know the game, fails this rule.
- Keep detail out of overview files like the README. Link to it instead.
- Talk to the reader, not to yourself. Assume they've never seen the study, and be friendly and clear.

## Commits

Commit before every major change. If the working tree has uncommitted work, commit it first, then start the change. This keeps each step easy to review and easy to roll back.
