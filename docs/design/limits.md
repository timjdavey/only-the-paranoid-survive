# Limits

| Limit | Why we accept it | What checks it |
|---|---|---|
| **A game, not a job.** Skins make it look like a job, but no run here is real work | A game is the only way to replay the same change for every model and know the true levels. Epoch makes the same argument for [EBR-bench](../prior/themes.md), a board game it calls a reasonable proxy for learning a job. Ours is a proxy argued the same way | If there is a marked difference in the skins, particularly game vs real narratives |
| **A fresh call each round.** The agent remembers what happened, as the full record is in every prompt, but not what it thought | Its own reasoning is the one place a model won't question a claim, and cost grows with the square of the run, see [interface](interface.md#rejected). Each round is a small handoff, which is how long-running agents already work | The [rolling conversation](../pilot/checks.md#rolling-conversation) and [notepad](../pilot/checks.md#notepad-and-compute) pilot checks, reported beside the headline |
| **Equal weight across scenarios is a prior.** The headline treats a switch as common as a shock. No real setting is known to | The headline is an AND over traits, not a forecast of output. A plain mean would let one trait hide another, see [scoring](scoring.md#why-a-mean-within-and-a-geometric-mean-across) | The trait profile is reported beside the headline, so a reader with a base rate can reweight |
| **The stories cut both ways.** Kodak and Peloton are picked with hindsight | They motivate the question. The grounding is the human finding of system neglect, see [people](../prior/people.md#massey-and-wu-2005-system-neglect) | The No change and One shock scenarios sit in the headline, so holding on and jumping both cost |
| **One skin in the proof of concept.** A model could be good at one story | Skin sensitivity is a finding, not an error, see [spread](scoring.md#spread) | More skins in the full study, each with its own headline |
| **No human baseline.** A score compares models with each other, not with people | Comparing models over time needs no human anchor | Not planned. Massey and Wu's map says which way people err |
| **The change never reacts to the agent.** Real plans often wear out because they are leaned on | A reactive change muddies the oracle, the seeds and the error bars | Not planned |
| **Switching is free.** A model that never moves still earns most of the output | The score prices lateness every round. A fee leaks into every trait | The [inertia](scoring.md#extension-inertia) extension, if the pilot finds scores flat |
